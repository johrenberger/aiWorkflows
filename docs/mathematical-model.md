# Mathematical model

For positive odd `n`, define `v₂(m)` as the largest `e` for which `2^e` divides `m`, then define

\[
T(n) = \frac{3n+1}{2^{v_2(3n+1)}}.
\]

This project formalizes sound intermediate propositions about finite trajectories, residue classes, affine compositions, and descent certificates. It asserts no global convergence result.
