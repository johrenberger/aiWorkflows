## Decisions made (this segment)

- **`D1`**: Use Vite 5 (not Create React App) — Vite is
  faster, has native ESM, and Vitest is its native test
  runner.
- **`D2`**: Implement WAI-ARIA 1.2 combobox by hand — the
  skill's react profile doesn't mandate a library, and
  the project is greenfield.
- **`D3`**: Use plain JavaScript (not TypeScript) —
  greenfield project is JS, skill says don't migrate.
- **`D4`**: No router — single-page demo, router would
  be out of scope.
- **`D5`**: Use `useId` for accessible IDs — React 18
  feature, ensures no ID collisions.
- **`D6`**: Use `mousedown` (not `click`) on combobox
  options — so the input doesn't lose focus first.
